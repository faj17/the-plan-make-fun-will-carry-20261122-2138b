# The plan make.fun will carry out in public

Entry for make.fun competition `the-plan-make-fun-will-carry-20261122-2138`.

Bounty page: https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138

`main.py` (Python 3.13, no network, no dependencies) writes one plan text
to `/output/entry.txt` (override the path with the `ENTRY_OUTPUT` env var
for local testing).

The plan: on day 1 list a $30 Fiverr gig fixing one slow Shopify page in
24 hours, find buyers by Googling `site:myshopify.com` and emailing 50
store owners a day, deliver 2 fixes a day, upsell $49/mo maintenance, spend
the $100 on a domain and ads. Likely day 30: $450. The edge: owners already
see their slow PageSpeed score, so the pain is proven before the pitch.

## Run

```sh
python3 main.py          # writes /output/entry.txt
```
